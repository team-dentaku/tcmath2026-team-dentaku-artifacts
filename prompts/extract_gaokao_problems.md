# Gaokao数学問題抽出・解法生成タスク

以下の日本語翻訳済みGaokao数学問題から、**独立した完結問題**を抽出し、それぞれに詳細な解法（reasoning）と答えを生成してください。

## 入力問題

```json
<<<|PROBLEM_JSON|>>>
```

## タスク

### 1. 問題の分析と独立化

与えられた問題を分析し、**1つの問題から複数の独立した問題が作れる場合は複数抽出**してください。

**【最重要】完全な独立性 (Self-Contained)**
- **各問題は完全に独立**: その問題だけを見て、他の情報なしで解けるようにする
- **すべての前提条件を含める**: 関数の定義、図形の条件、設定など、すべてを各問題に含める
- **省略しない**: 問題文は決して省略せず、完全な形で記載する
- **複数問題への展開**: 1つの問題から複数の観点で問題を作れる場合は積極的に展開する

**【絶対禁止】前の問題への参照**

以下のような表現は**絶対に使用禁止**です。参照している内容を直接問題文に含めてください。

**明示的な参照（絶対禁止）**:
- ❌ 「問題Nで求めた〜」
- ❌ 「前の問題で求めた〜」
- ❌ 「先ほど求めた〜」
- ❌ 「上記の〜」
- ❌ 「(M, Nは前の問題で求めた)」のような注釈
- ❌ 「問題1の結果を用いて〜」
- ❌ 「前問と同じ条件で〜」

**暗黙的な参照（絶対禁止）**:
- ❌ 「その放物線」「この直線」「この関数」 → どれを指すか不明
- ❌ 「同じ条件で」「同様に」 → 何と同じか不明
- ❌ 「また、〜を求めよ」 → 何に追加して求めるのか不明
- ❌ 「この場合」「このとき」 → どの場合・ときか不明
- ❌ 点M、点Nなど、座標が定義されていない点の使用
- ❌ パラメータの値（$p=8$ など）が問題文に含まれていない

**修正方法**:
- すべての対象を明示的に定義する
- 「その〜」→ 具体的な式や条件を再記述
- 点や値は必ず問題文内で定義する

**暗黙的参照を検出するためのチェック**:

問題文を読んだときに、以下の質問に「はい」と答えられない場合は暗黙的参照があります：

1. **この問題文だけで、すべての対象が特定できるか？**
   - 「その放物線」→ どの放物線？式は？
   - 「点M」→ 座標は？定義されている？

2. **この問題文だけで、すべての条件が分かるか？**
   - 「この場合」→ どの場合？条件は？
   - 「同じ条件で」→ どんな条件？

3. **この問題文だけで、必要なすべての値が分かるか？**
   - パラメータの値は明示されている？
   - 前提となる計算結果は含まれている？

**原則**: もし問題文を読んで「？」と思う箇所があれば、それは暗黙的参照です。すべてを明示してください。

#### 前問参照の修正例

**NG例1**: 前の問題の結果を参照
```
問題3で求めた二つの接線 $x-\sqrt{3}y+\sqrt{3}-4=0$ と $x+\sqrt{3}y-\sqrt{3}-4=0$ を、原点を極点、$x$ 軸の正方向を極軸とする極座標系で表しなさい。
```

**OK例1**: 接線の式を直接含める
```
二つの直線 $x-\sqrt{3}y+\sqrt{3}-4=0$ と $x+\sqrt{3}y-\sqrt{3}-4=0$ を、原点を極点、$x$ 軸の正方向を極軸とする極座標系で表しなさい。
```
→ 「問題3で求めた」を削除し、「二つの直線」と直接記述

**NG例2**: 前の問題で定義された点を参照
```
放物線 $C:\; y=\frac{x^{2}}{4}$ と直線 $y=a\;(a>0)$ が点 $M$，$N$ で交わるとき，$M$ と $N$ における接線の方程式をそれぞれ求めなさい。（M, Nは前の問題で求めた）
```

**OK例2**: 点M, Nを明示的に定義
```
放物線 $C:\; y=\frac{x^{2}}{4}$ と直線 $y=a\;(a>0)$ が点 $M(2\sqrt{a}, a)$，$N(-2\sqrt{a}, a)$ で交わるとき，$M$ と $N$ における接線の方程式をそれぞれ求めなさい。
```
→ 「(M, Nは前の問題で求めた)」を削除し、点Mと点Nの座標を直接記述

**NG例3**: 前問の条件を暗黙的に使用
```
前問と同じ放物線において、焦点を通る直線との交点を求めなさい。
```

**OK例3**: すべての条件を明示
```
放物線 $y^2 = 8x$ において、焦点 $(2, 0)$ を通る傾き $m$ の直線との交点を求めなさい。
```
→ 「前問と同じ放物線」を具体的な式に、焦点も明示

#### 暗黙的な参照の修正例

**NG例4**: 「その〜」による暗黙的な参照
```
その放物線の頂点を求めなさい。
```

**OK例4**: 放物線を明示的に定義
```
放物線 $y = x^2 - 4x + 3$ の頂点を求めなさい。
```
→ 「その放物線」を具体的な式に置き換え

**NG例5**: 座標が定義されていない点の使用
```
点Mと点Nを通る直線の方程式を求めなさい。
```

**OK例5**: 点の座標を明示
```
点 $M(2, 3)$ と点 $N(5, 7)$ を通る直線の方程式を求めなさい。
```
→ 点M、点Nの座標を明示的に定義

**NG例6**: パラメータの値が暗黙的
```
この場合の楕円の焦点を求めなさい。
```

**OK例6**: すべての条件を明示
```
楕円 $\frac{x^2}{25} + \frac{y^2}{9} = 1$ の焦点を求めなさい。
```
→ 「この場合」を削除し、楕円の式を明示

**NG例7**: 「同様に」による暗黙的な参照
```
同様に、$y$ 軸との交点を求めなさい。
```

**OK例7**: 対象を明示
```
直線 $y = 2x + 3$ と $y$ 軸との交点を求めなさい。
```
→ 「同様に」を削除し、対象の直線を明示

### 2. 複数問題への展開例

**例1: 放物線と楕円の問題**
```
元の問題: 放物線 $y^{2}=2 p x \quad(p>0)$ の焦点が楕円 $\frac{x^{2}}{3 p}+\frac{y^{2}}{p}=1$ の焦点の一つであるとき、$p=$ [選択肢]
```

**抽出する問題（複数に展開）**:
1. **問題1（元の問題）**: 「放物線 $y^{2}=2 p x \quad(p>0)$ の焦点が楕円 $\frac{x^{2}}{3 p}+\frac{y^{2}}{p}=1$ の焦点の一つであるとき、$p$ の値を求めなさい。」
2. **問題2（放物線の焦点）**: 「放物線 $y^{2}=2 p x \quad(p>0)$ の焦点の座標を求めなさい。」
3. **問題3（楕円の焦点）**: 「楕円 $\frac{x^{2}}{3 p}+\frac{y^{2}}{p}=1$ において、$p$ を定数とするとき、焦点の $x$ 座標を $p$ で表しなさい。」

**例2: 複素数の問題**
```
元の問題: $(1+i)x=1+yi$ とし、$x, y$ は実数である。このとき $|x+yi|=$ [選択肢]
```

**抽出する問題（複数に展開）**:
1. **問題1（元の問題）**: 「$(1+i)x=1+yi$ とし、$x, y$ は実数である。このとき $|x+yi|$ の値を求めなさい。」
2. **問題2（x, yの値）**: 「$(1+i)x=1+yi$ とし、$x, y$ は実数である。$x$ と $y$ の値をそれぞれ求めなさい。」

**例3: 集合の問題**
```
元の問題: 集合 $A=\{1,2,4\}$，$B=\left\{x \mid x^{2}-4 x+m=0\right\}$ とする。$A \cap B=\{1\}$ ならば、$B=$ [選択肢]
```

**抽出する問題（複数に展開）**:
1. **問題1（元の問題）**: 「集合 $A=\{1,2,4\}$，$B=\left\{x \mid x^{2}-4 x+m=0\right\}$ とする。$A \cap B=\{1\}$ のとき、集合 $B$ を求めなさい。」
2. **問題2（パラメータm）**: 「集合 $A=\{1,2,4\}$，$B=\left\{x \mid x^{2}-4 x+m=0\right\}$ とする。$A \cap B=\{1\}$ となるような $m$ の値を求めなさい。」
3. **問題3（方程式の解）**: 「$1 \in B$ であり、$B=\left\{x \mid x^{2}-4 x+m=0\right\}$ とする。このとき、$m$ の値と方程式 $x^{2}-4 x+m=0$ のもう一つの解を求めなさい。」

### 3. 問題文の整形

- 選択肢形式（A. B. C. D.）→ 直接答えを求める形に変換
- 「〜である」→「〜を求めなさい」に変換
- LaTeX数式はそのまま保持
- 自然で読みやすい日本語
- **元の問題文の内容は決して省略しない**
- **前問参照を削除**: 「問題Nで求めた〜」「前の問題で〜」などを検出し、参照内容を直接記述

### 4. 解法と思考過程の生成（reasoning）

**重要**: reasoningには**数学的な思考過程**と**詳細な解法説明**を含めてください。

**含めるもの**:
- 問題を見たときの最初の考え方
- 解法の方針（どの公式・定理を使うか）
- ステップバイステップの解法
- 途中式（LaTeX数式）
- 各ステップの説明（日本語）
- 元のanalysisフィールドの内容も参考にする

**reasoning生成時の注意**:
- 元のanalysisに基づいて、より詳細で段階的な解説を追加
- 「まず〜を考える」「次に〜を使う」など、思考の流れを明示
- 途中式を省略せず、すべて記載
- **元のanalysisに前問参照がある場合は排除する**（「(1)の結果を用いて」などは削除）

### 5. 答えの生成（answer）

**【絶対厳守】answerフィールドのLaTeX形式要件**

**必須ルール**:
1. **必ず `$` で開始し `$` で終了**: すべての答えは `$...$` の形式
2. **数式のみ**: 日本語の説明、接続詞、選択肢記号は一切含めない
3. **完全なLaTeX**: 数値も必ず `$` で囲む

**正しい例（OK）**:
- ✅ `"$8$"` （数値）
- ✅ `"$\\sqrt{2}$"` （根号）
- ✅ `"$\\{1,3\\}$"` （集合）
- ✅ `"$m=3$"` （方程式）
- ✅ `"$\\frac{1}{2}$"` （分数）
- ✅ `"$x=1, y=1$"` （複数の値）
- ✅ `"$\\left(\\frac{p}{2}, 0\\right)$"` （座標）

**間違った例（NG）**:
- ❌ `"答えは $8$ である"` → 日本語の説明を含む
- ❌ `"したがってD"` → 選択肢記号
- ❌ `"Dを選択"` → 選択肢記号
- ❌ `"8"` → `$` で囲まれていない
- ❌ `"$8$ です"` → 余計な日本語
- ❌ `"D: $8$"` → 選択肢記号を含む

**選択肢から答えへの変換ルール**:
1. 元のanswer: `["D"]`, 選択肢D: `8` → `"$8$"`
2. 元のanswer: `["B"]`, 選択肢B: `$\\sqrt{2}$` → `"$\\sqrt{2}$"`
3. 元のanswer: `["C"]`, 選択肢C: `$\\{1,3\\}$` → `"$\\{1,3\\}$"`

**重要**: 選択肢の記号（A, B, C, D）は**絶対に**含めず、選択肢に書かれた実際の数値や数式のみを抽出してください。

## 注意事項

### 複数問題への展開ルール

1. **元の問題は必ず含める**
   - 元の問題をそのまま独立した問題として必ず1つ目に含める

2. **展開可能な場合**
   - 問題に複数の要素（パラメータ、中間結果など）がある場合
   - それぞれの要素について独立した問題を作れる場合
   - 例: 「$p$ を求める」→ 「焦点を求める」「$m$ を求める」など

3. **展開しない場合**
   - 単純な計算問題で展開の余地がない場合
   - 1つの問題として完結している場合

### 問題IDの命名

- `{index}-{連番}` の形式
- 例: `143-1`, `143-2`, `143-3`

### answerフィールドの制約（再確認）

**【絶対厳守】すべての答えは必ずLaTeX形式**

1. **必ず `$...$` 形式**
   - すべての答えを `$` で囲む（数値も必須）
   - 日本語の説明を**絶対に**含めない
   - 選択肢記号（A, B, C, D）を**絶対に**含めない

2. **選択肢を数値に変換**
   - 元の answer が `["D"]` で選択肢Dが `8` なら → `"$8$"`
   - 元の answer が `["B"]` で選択肢Bが `$\\sqrt{2}$` なら → `"$\\sqrt{2}$"`
   - **重要**: 選択肢の記号は含めず、実際の数値・数式のみ

3. **形式の例**
   - 数値: `"$8$"`, `"$2$"`, `"$-1$"`
   - 分数: `"$\\frac{1}{2}$"`, `"$\\frac{-1}{2}$"`
   - 根号: `"$\\sqrt{2}$"`, `"$6\\sqrt{3}$"`
   - 集合: `"$\\{1,3\\}$"`
   - 複数解: `"$x=1, y=1$"`
   - 座標: `"$\\left(\\frac{p}{2}, 0\\right)$"`

**出力前の最終確認**:
- ✅ `$` で開始している
- ✅ `$` で終了している
- ✅ 日本語・選択肢記号が含まれていない

### **【最重要】answerフィールドのLaTeX形式チェック**

**出力前に必ず確認**:
