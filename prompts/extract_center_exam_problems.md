# センター試験問題抽出・解答生成タスク

以下のマークダウンファイルから、すべての小問を抽出し、それぞれに対して**独立した完結問題**として整形し、解法と答えを生成してください。

## 入力Markdown
```markdown
<<<|MARKDOWN_CONTENT|>>>
```

## タスク

### 1. 問題の抽出と独立化

各小問（`#### (1)`, `#### (2)` など）を抽出し、**前提条件を含めた完全に独立した問題文**にしてください。

**最重要原則: 完全な独立性 (Self-Contained)**
- **各問題は他の問題を参照しない**: (2)が(1)の設定を使う場合でも、(2)にすべての設定を再度記載する
- **すべての前提条件を毎回含める**: 袋の中身、関数の定義、図形の条件など、すべてを各問題に含める
- **問題文だけで完全に理解できる**: その問題だけを見て、何も追加情報なしで解けるようにする
- **前の問題への依存を排除**: 「先ほどの設定で」「(1)と同じ条件で」などの表現は使わない

**NG例**:
```
(1) A の袋には 1,3,5,7,9、B の袋には 2,4,6,8 が入っている...
(2) A と B がそれぞれ袋から 2 個ずつ球を取り出し...  ← NG: 袋の中身が不明
```

**OK例**:
```
(1) A の袋には 1,3,5,7,9、B の袋には 2,4,6,8 が入っている...
(2) A の袋には 1,3,5,7,9、B の袋には 2,4,6,8 が入っている。A と B がそれぞれ袋から 2 個ずつ球を取り出し...  ← OK: すべての情報を含む
```

#### 例1：前提条件の処理（対数）

**元のMarkdown**:
```markdown
### 〔１〕
$a=\log_{3}x$，$b=\log_{9}y$ とする。

#### (1)
$y=9^{b}$ であるから，$2b = \log_{3}y$ である。

#### (2)
$x^{2}y=\dfrac{1}{3}$ ならば，$a+b = \frac{-1}{2}$ である。
```

**抽出すべき独立問題**:
- **(1)**: 「$a=\log_{3}x$, $b=\log_{9}y$ とする。$y=9^{b}$ であるとき、$\log_{3}y$ を $b$ で表しなさい。」
- **(2)**: 「$a=\log_{3}x$, $b=\log_{9}y$ とする。$x^{2}y=\frac{1}{3}$ のとき、$a+b$ の値を求めなさい。」

→ 両方の問題に「$a=\log_{3}x$, $b=\log_{9}y$ とする」を含める

#### 例2：前提条件の処理（確率）

**元のMarkdown**:
```markdown
### 〔２〕
A の袋には $1,3,5,7,9$ の 5 個の球，B の袋には $2,4,6,8$ の 4 個の球が入っている。

#### (1)
各自が袋から 1 個ずつ取り出し，数が大きい方が勝ちとする。A の得点の期待値を求めよ。

#### (2)
A と B がそれぞれ袋から 2 個ずつ球を取り出し，取り出した数の和を比較する。2 人の和が等しくなる確率を求めよ。
```

**抽出すべき独立問題**:
- **(1)**: 「A の袋には $1,3,5,7,9$ の 5 個の球，B の袋には $2,4,6,8$ の 4 個の球が入っている。各自が袋から 1 個ずつ取り出し，数が大きい方が勝ちとする。勝者は自分が出した数を得点とし，負けた者の得点は $0$ とする。このとき，A の得点の期待値を求めなさい。」
- **(2)**: 「A の袋には $1,3,5,7,9$ の 5 個の球，B の袋には $2,4,6,8$ の 4 個の球が入っている。A と B がそれぞれ袋から 2 個ずつ球を取り出し，取り出した数の和を比較する。2 人の和が等しくなる確率を求めなさい。」

→ **重要**: 両方の問題に袋の中身の情報を含める。(2)で「A と B が」だけでは不十分！

### 2. 問題文の整形

- 「〜である」→「〜を求めなさい」に変換
- 解答欄プレースホルダー（`$\boxed{...}$`）は削除
- LaTeX数式はそのまま保持
- 自然で読みやすい日本語

### 3. 解法と思考過程の生成（reasoning）

**重要**: reasoningには**数学的な思考過程**と**解法説明**の両方を含めてください。

**含めるもの**:
- 問題を見たときの考え方（「この問題は...で解けそうだ」）
- 解法の方針（「...を使えば...」「まず...から始める」）
- ステップバイステップの解法
- 日本語の説明 + LaTeX数式
- 途中式

**含めないもの**:
- メタ的な内容（「マークダウンをパース...」「問題を抽出...」など）
- タスクに関する説明
- 純粋に数学問題を解く思考のみを記載

### 4. 答えの生成（answer）

**最重要**: **answerフィールドにはLaTeX形式の数または数式のみ**を含めてください。
- ✅ OK: `"$2b$"`, `"$\frac{-1}{2}$"`, `"$6\sqrt{3}$"`
- ❌ NG: `"答えは $2b$ である"`, `"したがって $2b$"`
- ❌ NG: 日本語の説明を含めない

## 注意事項

### 前提条件の扱い

1. **共通の前提条件を見極める**
   - 同じ `###` セクション内の小問は通常同じ前提条件を共有
   - **各小問に必要な前提条件をすべて毎回含めること**（繰り返しでもOK）

2. **前提条件が不要な場合**
   - 小問が完全に独立している場合は前提条件なしでOK

3. **連続的な問題の場合（最重要）**
   - **(2)が(1)の設定を使う場合でも、(2)にすべての設定を再度記載する**
   - 前提条件の繰り返しを恐れない（独立性が最優先）
   - NG: 「先ほどの設定で」「(1)と同じ条件で」「上記と同様に」
   - OK: すべての前提条件を(2)にも完全に記載する

**具体例**:
```
NG: (2) 同じ袋から2個ずつ取り出すとき...
OK: (2) A の袋には 1,3,5,7,9、B の袋には 2,4,6,8 が入っている。各自が袋から2個ずつ取り出すとき...
```

### answerフィールドの制約

1. **必ずLaTeX数式のみ**
   - 日本語の説明を絶対に含めない
   - `$` または `$$` で囲む

2. **複数の答え**
   - カンマ区切り: `"$x=1, 2$"`
   - または: `"$x=1$ または $x=2$"`

3. **形式**
   - 分数: `"$\\frac{4}{3}$"`
   - 根号: `"$\\sqrt{3}$"`, `"$6\\sqrt{3}$"`
   - 対数: `"$\\log_{3}y$"`, `"$2b$"`
   - 等式: `"$x=1$"`, `"$a+b=\\frac{-1}{2}$"`

### 問題文が不完全な場合の対応

**基本方針**: **できる限り問題を抽出してください。** 不完全な情報でも、推測・補完して問題を成立させてください。

#### 問題文の補完方法

**周囲の文脈から推測**:
- 前後のセクションの内容を参考にする
- 同じセクション内の他の小問から共通テーマを推測
- 数式や解答から逆算して問題を推測

**解答から逆算**:
- 解答が `$x=3$` なら → 「$x$ の値を求めなさい」
- 解答が `$\frac{1}{2}$` なら → 「確率/比/値を求めなさい」
- 解答が `$x=1, 2$` なら → 「方程式を解きなさい」

**画像・図表参照の扱い**:
- `**[図: ファイル名]**` がある → 「次の図を参照して...」のように自然に組み込む
- 「正規分布表を用いて」→ そのまま問題文に含める
- 図の内容が不明でも、問題として成立させる

#### 補完の具体例

**例1**: 解答のみの場合
```markdown
#### (1)
$$\frac{1}{2}$$
```
→ 前後の文脈から「確率を求める問題」と判断
→ **question**: 「この事象が起こる確率を求めなさい。」

**例2**: 不完全な問題文
```markdown
#### (1)
次の図を参照して、
$$x=3$$
```
→ **question**: 「次の図を参照して、$x$ の値を求めなさい。**[図: ファイル名]**」

**例3**: 周囲の文脈を利用
```markdown
### 〔１〕
$f(x)=x^2+2x+1$ とする。

#### (1)
$$x=-1$$
```
→ 文脈から「$f(x)=0$ の解を求める問題」と推測
→ **question**: 「$f(x)=x^2+2x+1$ とする。$f(x)=0$ となる $x$ の値を求めなさい。」

#### スキップする条件（これだけ）

**完全にスキップする場合**（以下の場合のみ）:
- 「（問題文は省略）」という明示的な記述がある
- 問題文も解答も文脈も全くなく、推測不可能な場合

**重要**: 上記以外の場合は、**必ず推測・補完して問題を抽出**してください。不完全でも、合理的な推測に基づいて問題文を作成してください。

### セクション情報

- `section`: `## 【１】` → `"【１】"`
- `subsection`: `### 〔１〕` → `"〔１〕"`
- `problem_id`: サブセクションと小問番号を結合（例: `"〔１〕-(1)"`）

## 期待される処理

1. マークダウン全体を解析
2. 構造を理解（大問、中問、小問）
3. 各小問に必要な前提条件を判断
4. **不完全な問題は文脈・解答から推測して補完**
5. 独立した問題文を生成
6. 解法を推論
7. 答えをLaTeX形式のみで抽出
8. すべてをJSON配列で出力

### 補完時の注意

- **合理的な推測**: 完全な創作はせず、文脈に基づいた合理的な推測をする
- **明示的な記載**: 推測した部分は問題文に自然に組み込む（「推測」などと書かない）
- **数学的妥当性**: 解答と整合性のある問題文にする

---

## 最重要チェックリスト

各問題を出力する前に、以下を確認してください：

✅ **完全な独立性**: その問題だけを見て、他の問題を参照せずに解けるか？
✅ **前提条件の完全性**: 必要な設定・定義・条件がすべて含まれているか？
✅ **参照の排除**: 「先ほど」「上記」「(1)と同じ」などの表現がないか？
✅ **繰り返しOK**: 同じ前提条件を複数の問題で繰り返すことを恐れない

**最重要原則**: 各問題は完全に独立（self-contained）であること。前提条件の繰り返しを恐れず、すべての情報を各問題に含めること。
