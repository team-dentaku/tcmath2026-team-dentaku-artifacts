# 数学問題抽出タスク
## タスク内容
次のテキストファイルに記載された、数学の問題と回答の組み合わせを**JSONL形式**で全て抽出してください。問題の解法についても記載がある場合は、それも抽出してください。
また、その問題の単元 (e.g., 微分/積分/三角関数) 等もアノテーションしてください。

## 出力形式

```json
{
    "question": str,      // 問題文
    "reasoning": null | str,  // 解法（ある場合）
    "answer": str,        // 回答
    "unit": str           // 単元
}
```

## 出力例

```json
{
	"question": "次の式を簡単にしなさい。$\frac{6x+2}{3}\div\frac{4}{9}$",
	"reasoning": "$\frac{6x+2}{3}\div\frac{4}{9}=\frac{6x+2}{3}\times\frac{9}{4}=\frac{(6x+2)\,9}{12}=\frac{3}{4}\,(6x+2)=\frac{18x+6}{4}=\frac{9x+3}{2}$",
	"answer": "$\frac{9x+3}{2}$",
	"unit": "文字と式"
}
```

## 注意点
- 出力する数式はlatex形式とし、必ず$...$で数式を囲んでください。
- answerは必ず$...$で囲まれた数式のみとしてください。単位 (e.g., ℃ )等の数字/数式以外のものは不要です。
- answerを数式のみでは表現不可能な場合 (e.g., 証明問題) は抽出不要です。
- テキスト内に存在する全ての数学問題を抽出してください。
- 回答には答えの数字や式だけを記載してください。
- 解法がない場合は、reasoningフィールドをnullにしてください。
- 問題文に複数の設問がある場合は、それぞれを独立したJSONオブジェクトとして出力してください。
