# センター試験問題XMLからMarkdown変換タスク

以下のセンター試験問題XMLと解答XMLから、**解答を穴埋めしたMarkdown形式**の試験問題ドキュメントを生成してください。

## 入力

### 問題XML
```xml
<<<|PROBLEM_XML|>>>
```

### 解答XML
```xml
<<<|ANSWER_XML|>>>
```

## タスク

1. **解答マッピングの作成**:
   - 解答XMLから `anscolumn_ID` と `answer` の対応を取得
   - 例: `anscolumn_ID="1ア,1イ,1ウ"`, `answer="1,3,2"` → `{"1ア":"1", "1イ":"3", "1ウ":"2"}`
   - カンマ区切りの場合は個別にマッピング

2. **MathML→LaTeX変換**:
   - `<math>` タグ内のMathMLをLaTeX形式に変換
   - `anscolumn_id` 属性がある要素は解答値に置換
   - インライン数式: `$...$`
   - ディスプレイ数式（必要に応じて）: `$$...$$`

3. **階層構造の保持**:
   - タイトル: `# タイトル`（H1）
   - 大問【１】: `## 【１】`（H2）
   - 中問〔１〕: `### 〔１〕`（H3）
   - 小問(1): `#### (1)`（H4）
   - `minimal="no"` の question は親要素として扱い、子要素を再帰処理

4. **要素の処理**:
   - `<label>`: 見出しテキストとして使用
   - `<info>`: 見出しに追加情報として付加（例: 〔必答問題〕、(配点 40)）
   - `<instruction>`: 問題文として出力
   - `<br/>`: 改行に変換
   - `<img>`: `![画像: ファイル名](ファイル名)` 形式に変換
   - `<data type="image">`: 画像への参照として `**[図: ファイル名]**` のように記載

## 出力形式

Markdown形式のテキストを直接出力してください。```markdown フェンスで囲まないでください。

### Markdown構造例

```
# 1997年度 本試験 数学Ⅰ・Ａ

【１】【２】…必答問題，【３】【４】【５】…選択問題(1題選択)

---

## 【１】 〔必答問題〕 (配点 40)

### 〔１〕

2次関数 $y=\frac{9}{4}x^{2} + ax + b$ のグラフを $C$ とし、$C$ が2点 $(0, 4)$ と $(2, k)$ を通るとする。このとき

$$a=\frac{k-13}{2}, \quad b=4$$

である。

#### (1)

グラフ $C$ が $x$ 軸と接するのは

$$k=1, \quad k=25$$

のときであり、接点の $x$ 座標はそれぞれ

$$x=\frac{4}{3}, \quad x=\frac{-4}{3}$$

である。
```

## 重要な指示

### 解答の穴埋めルール

1. **anscolumn_id の置換**:
   - MathML内の `<mi anscolumn_id="1ア,1イ">アイ</mi>` → 解答値 `13` に置換
   - `<mi anscolumn_id="1ウ">ウ</mi>` → 解答値 `2` に置換

2. **カンマ区切り解答の処理**:
   - `answer="1,3,2"` は連結して `132` として使用
   - マイナス記号 `answer="-,4,3"` の場合は `-43` として使用
   - 解答XMLの各anscolumn_IDを個別に分解してマッピング

3. **数式の適切な配置**:
   - 短い式はインライン: `$k=1$`
   - 複数の式が並ぶ場合はディスプレイ: `$$k=1, \quad k=25$$`
   - 分数を含む式はディスプレイ推奨

### MathML→LaTeX変換ルール

- `<mfrac>`: `\frac{分子}{分母}`
- `<msup>`: `{基底}^{指数}`
- `<msub>`: `{基底}_{添字}`
- `<msqrt>`: `\sqrt{内容}`
- `<mfenced>`: 括弧 `(...)`, `[...]` など
- `<mi>`: 変数名そのまま
- `<mn>`: 数値そのまま
- `<mo>`: 演算子（特殊記号は変換: `×` → `\times`, `≦` → `\leq`）

### 見出しレベルの決定

- `<exam>` の `<title>`: `# タイトル`
- `<question minimal="no">` の最上位: `## ラベル`
- `<question minimal="no">` のネスト: レベルを1つ上げる（最大 `######`）
- `<question minimal="yes">`: 親のレベル+1

## 注意事項

- 解答値は正確に置換してください
- MathML構造を正しくLaTeXに変換してください
- Markdown見出しの階層を正しく保ってください
- 不要な空行を減らし、読みやすいフォーマットにしてください
- `<br/>` は改行 `\n` に変換してください
- **出力は生のMarkdownテキストのみで、コードフェンスで囲まないでください**

### 重要: 画像を含む問題の扱い

**絶対に「（問題文は省略）」のような省略をしないでください。**

画像を含む問題でも：
1. **問題文のテキスト部分はすべて出力**してください
2. 画像タグは `**[図: Center-2017--Main-SuugakuIIB-001.PNG]**` のように変換
3. 画像参照がある場合は、その旨を明記（例: 「次の図を参照」「正規分布表を用いて」）
4. 解答の数式部分もすべて変換して出力

**例**: 画像を含む問題の変換

**入力XML**:
```xml
<instruction>
次の<ref target="D2">図</ref>を参照して問題を解きなさい。
<data id="D2" type="image">
    <img src="Center-2017--Main-SuugakuIIB-001.PNG"/>
</data>
</instruction>
```

**出力Markdown**（正しい）:
```markdown
次の図を参照して問題を解きなさい。

**[図: Center-2017--Main-SuugakuIIB-001.PNG]**
```

**出力Markdown**（間違い - このようにしないこと）:
```markdown
（問題文は省略）
```
