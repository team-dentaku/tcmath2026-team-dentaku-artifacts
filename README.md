# チーム dentaku @ FT-LLM 2026

このリポジトリでは、[FT-LLM 2026 チューニングコンペティション](https://llm-jp.github.io/tuning-competition/2026/feature.html) に参加したチーム dentaku のプロンプトや関連データなどのリソースを公開しています。

## ディレクトリ構成

主なディレクトリ構成と内容は以下の通りです。

- `prompts/`: 合成データセットの構築に使用したプロンプト
- `prompts_for_inference/`: llm-jp-v4 の学習・推論に使用したプロンプト
- `data/list_of_learning_items.jsonl`: 合成データセットの構築に使用した学習項目のリスト

各プロンプトの用途などの詳細については、[システムレポート](https://llm-jp.github.io/tuning-competition/2026/pdfs/math_team003_report.pdf) を参照してください。

# Team dentaku @ FT-LLM 2026

This repository publishes resources such as prompts and related data from Team dentaku for the [FT-LLM 2026 Tuning Competition](https://llm-jp.github.io/tuning-competition/2026/feature.html).

## Directory Structure

The main directory structure and contents are as follows.

- `prompts/`: Prompts used to construct the synthetic dataset
- `prompts_for_inference/`: Prompts used for training and inference with llm-jp-v4
- `data/list_of_learning_items.jsonl`: List of learning items used to construct the synthetic dataset

For details on the purpose of each prompt, please refer to the [system report](https://llm-jp.github.io/tuning-competition/2026/pdfs/math_team003_report.pdf).
